Require ``total_length`` on ``partition_softmax`` / ``partition_ids`` (shape-size for the flattened axis; not a silent ``sum(partitions)``). ``num_segments`` is not an argument on partition helpers — it is ``shape(partitions)[0]``. Segment ops still require ``num_segments``. ``partition_cache`` is a decorator (preferred on library apply; GraphNetwork uses it), a reentrant context, and ``enable``/``disable`` for use outside a block; ``purge``/``purge_cache`` drops one tensor. GC callbacks hold only a weakref to the cache map so a long-lived tensor cannot zombie the block. ``anytensor.jraph.partition_softmax`` keeps official jraph's third positional ``sum_partitions`` (alias of ``total_length``) but now requires it.
