Require ``num_segments`` and ``sum_partitions`` on ``partition_softmax`` (JAX shape-size rule; ``num_segments`` matches ``segment_softmax``). Omitting them or passing ``None`` is a TypeError — not a silent ``sum(partitions)``. Convert with ``partition_ids``; opt-in ``partition_cache()`` makes partition helpers reuse ids for the same tensors in a block via weakrefs (GraphNetwork enters one per apply; GC drops entries). ``anytensor.jraph.partition_softmax`` keeps official jraph's third positional ``sum_partitions`` but now requires it.
