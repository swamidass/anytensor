Require ``sum_partitions`` on ``partition_softmax`` / ``partition_ids`` (JAX shape-size rule; not a silent ``sum(partitions)``). ``num_segments`` is not an argument on partition helpers — it is ``shape(partitions)[0]``. Segment ops still require ``num_segments``. Opt-in ``partition_cache()`` makes partition helpers reuse ids for the same tensors in a block via weakrefs (GraphNetwork enters one per apply). GC callbacks hold only a weakref to the cache map so a long-lived tensor cannot zombie the block. ``anytensor.jraph.partition_softmax`` keeps official jraph's third positional ``sum_partitions`` but now requires it.
