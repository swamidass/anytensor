Add the opt-in ``anytensor.export`` subpackage (not in ``anytensor.__all__``) as an unstable guide for serializing AnyTensor callables. **ONNX is the recommended target** (ONNX Runtime is well tested for deployment); AnyTensor does not run ops on ORT. Dynamic / symbolic lengths; constructors take sizes from ``at.shape``; ``partition_softmax`` requires ``num_segments`` and ``sum_partitions=at.shape(logits)[0]``. Hetero and jraph model zoos export through the same TF path. Flax/JAX weights rebind as embedded initializers: Torch ``nn.Parameter`` (best names) or in-trace TF constants via ``as_tensorflow_fn`` — not outer tensors or extra graph inputs. Torch segment ops no longer ``int()`` ``num_segments``, so ``at.shape(x)[0]`` stays a symbolic size.
